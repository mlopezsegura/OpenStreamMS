Nueva sesión

General

Sesión de Windows en segundo plano, independiente del escritorio de este PC.
Sunshine transmite el escritorio físico de este PC con el usuario que lo tenga abierto. Al detenerla no se cierra la sesión de Windows. Solo puede haber una.
Sesión local: transmite el escritorio físico de este PC con el usuario que lo tenga abierto.
Un usuario conservado mantiene su perfil: el login de Steam, las partidas guardadas y los ajustes de los juegos.
Se comprueban solas al crear la sesión.

Pantalla

La del dispositivo donde vas a jugar (TV, portátil…).

Streaming

Moonlight en PC, móvil o consola; WebRTC en TVs Samsung con Moonlight WebRTC (requiere la build de sunshine-webrtc).

Acerca de

OpenStreamMS
Game Streaming Service para Windows

Servicio Windows que crea y gestiona sesiones RDP aisladas para streaming de juegos con Sunshine y Moonlight. Permite tener múltiples sesiones de streaming independientes, cada una con su propio perfil y ciclo de vida, todo controlado desde una interfaz web o API REST.

⚡
Sesiones RDP aisladas
Cada sesión corre bajo su propio usuario Windows con Sunshine independiente
🔀
Perfil de stream independiente
Abre Steam, Chrome o cualquier app simultáneamente en local y en stream sin conflictos
🖥️
Puestos locales
Varias personas en el mismo PC, cada una con su monitor, teclado, ratón, mando y audio
🔔
Icono en la bandeja
Control rápido de sesiones desde la barra de notificaciones de Windows
🔁
Auto-arranque y monitorización
Las sesiones habilitadas se relanzan automáticamente y se monitorizan cada 5 s
Proyectos utilizados
FreeRDP Cliente RDP para crear la sesión de stream Sunshine Servidor de streaming compatible con Moonlight HidHide Aísla cada mando en su sesión de Windows ViGEmBus Driver de gamepad virtual para el mando remoto TermWrap (llccd) Habilita varias sesiones RDP simultáneas en Windows cliente, Home incluido, y permite conectar RemoteIdd a RDP.
