OpenStreamMS is a Windows service that runs several independent Sunshine game-streaming sessions at once — each one inside its own isolated RDP session, with its own user, desktop, audio and Moonlight clients — all managed from a web dashboard. OpenStreamMS es un servicio de Windows que ejecuta varias sesiones de streaming de juegos con Sunshine a la vez, cada una dentro de su propia sesión RDP aislada, con su usuario, escritorio, audio y clientes Moonlight, y todo se gestiona desde un panel web.

How it worksCómo funciona

A dedicated streaming host per sessionUn host de streaming dedicado por sesión

The service (running as SYSTEM) opens a loopback RDP session for each stream, launches a private Sunshine instance inside it on its own ports, and keeps everything alive. Your local desktop is never touched. El servicio (que corre como SYSTEM) abre una sesión RDP local por cada stream, lanza dentro una instancia privada de Sunshine con sus propios puertos y lo mantiene todo en marcha. Tu escritorio local no se toca.

FeaturesCaracterísticas

Everything a multi-seat streaming box needsTodo lo que necesita un PC de streaming multipuesto

From session isolation to hardware encoding checks, OpenStreamMS automates the fiddly parts of running Sunshine headless.Desde el aislamiento de sesiones hasta la comprobación del encoder por hardware, OpenStreamMS automatiza lo más engorroso de usar Sunshine sin pantalla.

Sessions & isolationSesiones y aislamiento

Multiple isolated sessionsVarias sesiones aisladas

Each stream gets its own RDP session and its own Sunshine instance, with separate ports, config, logs and paired devices.Cada stream tiene su propia sesión RDP y su propia instancia de Sunshine, con puertos, configuración, logs y dispositivos emparejados independientes.

Native per-session usersUsuarios nativos por sesión

Optionally runs a session under an auto-managed local user (osms-…): its own profile, HKCU, desktop and audio. Steam or Chrome can run twice without lock conflicts. No drivers, no third-party tools.Opcionalmente ejecuta la sesión con un usuario local gestionado automáticamente (osms-…): perfil, HKCU, escritorio y audio propios. Steam o Chrome pueden abrirse dos veces sin conflictos de bloqueo. Sin drivers ni herramientas externas.

Ephemeral modeModo efímero

Isolated users can be ephemeral: the profile and its registry hive are wiped when the session stops, so every start is a clean slate.Los usuarios aislados pueden ser efímeros: el perfil y su registro se borran al parar la sesión, así que cada arranque empieza de cero.

Independent stream profilePerfil de stream independiente

Same Windows user, separate profile root: USERPROFILE, APPDATA, LOCALAPPDATA, temp and XDG paths are redirected for Explorer, Sunshine and every app launched from Moonlight.Mismo usuario de Windows con una raíz de perfil aparte: USERPROFILE, APPDATA, LOCALAPPDATA, temporales y rutas XDG se redirigen para Explorer, Sunshine y cada app lanzada desde Moonlight.

Sandboxie-Plus integrationIntegración con Sandboxie-Plus

Detects, installs and keeps Sandboxie-Plus boxes in sync for sessions that prefer copy-on-write sandboxing.Detecta, instala y sincroniza las cajas de Sandboxie-Plus para las sesiones que prefieran aislamiento copy-on-write.

Silent host, full stream audioHost en silencio, audio completo en el stream

The RDP client’s audio is muted on the host through WASAPI, while Sunshine still captures it for Moonlight. No game sound leaking into the room.El audio del cliente RDP se silencia en el host mediante WASAPI, mientras Sunshine lo sigue capturando para Moonlight. El sonido del juego no se oye en la habitación.

Streaming performanceRendimiento del streaming

4K60 RDP tuningRDP optimizado para 4K60

Applies frame-rate, GPU-capture and display-refresh policies before each session so the remote desktop composes at the full target rate. Resolution, fps and colour depth are set per session.Aplica políticas de fps, captura por GPU y frecuencia de pantalla antes de cada sesión para que el escritorio remoto se componga a la tasa completa. Resolución, fps y profundidad de color se configuran por sesión.

Hardware encoder guardControl del encoder por hardware

After launch it reads Sunshine’s encoder probe (NVENC, AMF, Quick Sync). If Sunshine fell back to software encoding, it relaunches once to recover the GPU encoder.Tras el arranque lee la detección de encoders de Sunshine (NVENC, AMF, Quick Sync). Si Sunshine ha caído a codificación por software, lo relanza una vez para recuperar el encoder de la GPU.

mstsc or FreeRDPmstsc o FreeRDP

Uses the Windows RDP client with H.264 hardware decoding when available, or the bundled FreeRDP client in headless mode — selectable in the config.Usa el cliente RDP de Windows con decodificación H.264 por hardware si está disponible, o el cliente FreeRDP incluido en modo oculto; se elige en la configuración.

Virtual gamepadsMandos virtuales

Installs and manages the ViGEmBus driver from the dashboard so Moonlight controllers appear as native Xbox/DualShock pads inside each session.Instala y gestiona el driver ViGEmBus desde el panel para que los mandos de Moonlight aparezcan como mandos Xbox/DualShock nativos en cada sesión.

Virtual display supportSoporte de pantalla virtual

Optional VDD mode keeps a virtual display alive for Sunshine even when the RDP client disconnects. Capture method, encoder and output display are configurable per session.El modo VDD opcional mantiene una pantalla virtual activa para Sunshine aunque se desconecte el cliente RDP. Método de captura, encoder y pantalla de salida se configuran por sesión.

Auto-recoveryRecuperación automática

A 5-second monitor restarts Sunshine if it crashes (reading the cause from the Windows event log) and relaunches every enabled session when the service or PC starts.Un monitor cada 5 segundos reinicia Sunshine si falla (leyendo la causa en el registro de eventos de Windows) y relanza todas las sesiones habilitadas cuando arranca el servicio o el PC.

ManagementGestión

Web dashboardPanel web

Create, start, stop, restart and delete sessions, edit their settings and follow live logs from any browser. Available in English, Spanish, French and Portuguese.Crea, inicia, detiene, reinicia y borra sesiones, edita su configuración y sigue los logs en directo desde cualquier navegador. En inglés, español, francés y portugués.

Moonlight pairingEmparejamiento con Moonlight

Enter the Moonlight PIN in the dashboard, list paired clients and unpair them. Pairings survive restarts and Sunshine updates.Introduce el PIN de Moonlight en el panel, consulta los clientes emparejados y desemparéjalos. Los emparejamientos se conservan tras reinicios y actualizaciones de Sunshine.

Sunshine stays privateSunshine queda privado

Each Sunshine admin panel is reached only through an authenticated reverse proxy with per-session internal credentials (optionally rotated on start). It is never exposed to the network.Al panel de administración de cada Sunshine solo se llega a través de un proxy inverso autenticado con credenciales internas por sesión (opcionalmente rotadas en cada arranque). Nunca se expone a la red.

Remote power controlsControl de energía remoto

Shut down, restart or cancel a pending shutdown of the host PC straight from the dashboard — handy from the couch.Apaga, reinicia o cancela un apagado pendiente del PC directamente desde el panel, muy práctico desde el sofá.

Concurrent RDP helpersAyudas para RDP concurrente

Native Remote Desktop is enabled automatically. For several simultaneous sessions on client editions of Windows, TermWrap (or RDP Wrapper as fallback) can be installed, updated and removed from the UI.Escritorio Remoto nativo se habilita automáticamente. Para varias sesiones simultáneas en ediciones cliente de Windows, TermWrap (o RDP Wrapper como alternativa) se puede instalar, actualizar y quitar desde el panel.

Your Sunshine settings are keptSe respetan tus ajustes de Sunshine

Only the keys OpenStreamMS needs (ports, paths, certificates) are managed. Anything you change in Sunshine’s own panel is preserved across restarts and upgrades.Solo se gestionan las claves que necesita OpenStreamMS (puertos, rutas, certificados). Lo que cambies en el panel de Sunshine se conserva entre reinicios y actualizaciones.
